# Workflow master copy: Backlog (open work)

Open work on the session workflow itself. It is built here first, then rolled out to every repo that uses the
workflow (intranet, KolLab.extension, website), adjusted to each project. A workflow to-do never goes into one
repo's own backlog.

**Rules**
- **No finished work.** When an item lands in master and in every repo, delete it; git has the history.
- An item is what is wrong or missing, a pointer to the detail, and when it is **done**.
